# Материалы к документации ЛР4

Тема: «Лабораторные синтезы — расчёт выхода продукта». В ЛР4 реализован сервер каталога синтезов с длительностью и температурой; отдельная формула расчёта выхода в исходных ЛР1–3 не задана и в ЛР4 не добавляется.

## Техническое задание на итоговую систему

### 1. Цель
1.1. Разработать интернет-приложение для публикации и просмотра карточек лабораторных синтезов, поиска по длительности и отметки понравившихся публикаций.

### 2. Назначение
2.1. Гость просматривает опубликованные карточки и ленту. Зарегистрированный создатель дополнительно готовит собственный черновик, загружает фото и видео, публикует и удаляет свои карточки, ставит и снимает лайки.

### 3. Задачи
3.1. Создать серверные страницы и стиль приложения: FastAPI, Jinja2, HTML, CSS, MinIO (ЛР1).
3.2. Спроектировать и подключить PostgreSQL с SQLAlchemy и Alembic (ЛР2).
3.3. Разработать REST API бизнес-процесса и коллекцию Postman (ЛР3).
3.4. Добавить сессии Redis, HttpOnly cookie, регистрацию, вход, выход и Swagger (ЛР4).
3.5. Разработать гостевой SPA на React и TypeScript (план ЛР5).
3.6. Подключить SPA к API и реализовать действия пользователя согласно последующим заданиям курса (план ЛР6).
3.7. Завершить клиентское приложение и предусмотренные курсом сценарии на React/TypeScript (план ЛР7; точный объём уточняется по заданию соответствующей работы).
3.8. Разместить демонстрационный фронтенд на GitHub Pages с PWA (план).
3.9. Оформить РПЗ, ТЗ, ER-, class- и sequence-диаграммы в StarUML.
3.10. Вести историю изменений в Git, сохраняя отдельные ветки лабораторных; публикация на GitHub выполняется владельцем либо по его явному разрешению.

### 4. Функциональные требования
4.1. HTTP-методы перечислены в таблице ниже. Входные модели запрещают дополнительные системные поля. Удаление логическое. Для пользователя допустим один черновик, повторная публикация запрещена.
4.2. Меню итоговой системы: каталог, лента, добавление, вход/выход. Для гостя операции изменения недоступны; API независимо проверяет права.
4.3. Окно аутентификации: регистрация и вход через домен пользователей; выход удаляет сессию и cookie. В ЛР4 роль интерфейса входа выполняет Swagger.
4.4. Каталог: GET списка с фильтром максимальной длительности; создатель видит признак собственной записи и может вызвать DELETE.
4.5. Лента: GET первой/следующей карточки; POST лайка для авторизованного пользователя. Гость видит количество лайков без собственного лайка.
4.6. Добавление: GET собственного черновика; POST названия и файлов; PUT описания, длительности и температуры для публикации. Автор и даты задаются сервером.

### 5. Аппаратные требования
5.1. Для учебного стенда предлагается сервер/ПК с 4 ядрами, 16 ГБ RAM и 20 ГБ свободного диска; это исходная рекомендация, не результат нагрузочного теста. Медиа требуют дополнительного дискового пространства.
5.2. Клиент: компьютер с браузером, 2 ядра и 4 ГБ RAM; сеть до сервера. Для демонстрации нужен доступ к консоли Redis и Postman/Insomnia.

### 6. Программные требования
6.1. Сервер: Python 3.12; FastAPI 0.115.0, SQLAlchemy 2.0.36, Alembic 1.14.0, asyncpg 0.30.0, redis-py 5.2.1; остальные зависимости зафиксированы в requirements.txt и requirements-lock.txt.
6.2. Сервисы: PostgreSQL 15, Redis 7, MinIO и Adminer из docker-compose.yml. Исходные MinIO/Adminer используют плавающий тег latest; фактические версии фиксируются перед защитой командой `docker compose images`.
6.3. Клиент: браузер с поддержкой cookie, Fetch и HTML5 video; Postman либо Insomnia. Для локальной демонстрации — Docker Desktop. Номера установленных версий браузера и Docker следует внести в итоговое ТЗ со своего компьютера.

## Таблица методов веб-сервиса

Все URL ниже начинаются с `/api`. Системный пользователь из ЛР3 заменён реальным пользователем сессии.

| Метод | URL | Доступ | Назначение и основные ответы |
|---|---|---|---|
| GET | /laboratory_syntheses | Все | Каталог, фильтр laboratory_synthesis_max_duration, 200 |
| GET | /laboratory_syntheses/feed и /feed/{id}?next=true | Все | Карточка ленты, 200/404 |
| GET | /laboratory_syntheses/draft | Автор | Свой черновик, 200/401/404 |
| POST | /laboratory_syntheses | Автор | Название + фото + видео, 201/401/409/415/422/503 |
| PUT | /laboratory_syntheses/draft/publication | Автор | Публикация собственного черновика, 200/401/409/422 |
| DELETE | /laboratory_syntheses/{id} | Владелец | Логическое удаление, 204/401/403/404 |
| POST | /laboratory_syntheses/{id}/likes | Авторизованный | Установить/снять свой лайк, 200/401/404/422 |
| POST | /laboratory_synthesis_users | Все | Регистрация с хешем пароля, 201/409/422 |
| POST | /laboratory_synthesis_users/login | Все | Вход, новая сессия и cookie, 200/401/422/503 |
| POST | /laboratory_synthesis_users/logout | Все | Завершить текущую сессию, 204/503 |

Выход идемпотентен: без cookie тоже возвращает 204. Ошибочная/истёкшая cookie трактуется как гость; закрытые методы отвечают 401. Сбой Redis с предъявленной cookie возвращает 503. Чтение без cookie не обращается к Redis.

## Диаграмма последовательности: данные для StarUML

Lifeline: «Клиент», «Пользователи синтезов», «Лабораторные синтезы». БД, Redis и нативное приложение не включать в эту диаграмму по условию курса.

Создайте операции доменов в существующей диаграмме классов с точными именами из таблицы. Для каждого сообщения выберите соответствующую операцию через `signature`; не ограничивайтесь вводом её имени. В `arguments` укажите параметры ниже. Между запросами добавьте ответ пунктирной стрелкой.

| № | Домен / операция для signature | arguments запроса | Ответ |
|---|---|---|---|
| 1 | Пользователи / laboratory_synthesis_users_login | name, password | 200, user_id, Set-Cookie: session_id |
| 2 | Синтезы / laboratory_syntheses_list | max_duration=45, cookie | 200, список опубликованных |
| 3 | Синтезы / laboratory_syntheses_save_draft | name, image, video, cookie | 201, draft_id, creator_id |
| 4 | Синтезы / laboratory_syntheses_get_draft | cookie | 200, собственный черновик |
| 5 | Синтезы / laboratory_syntheses_publish | description, duration_minutes, temperature_celsius, cookie | 200, published, formed_at |
| 6 | Синтезы / laboratory_syntheses_get_feed | cookie | 200, первая карточка |
| 7 | Синтезы / laboratory_syntheses_get_feed | id, next=true, cookie | 200, следующая карточка |
| 8 | Синтезы / laboratory_syntheses_set_like | id, liked=1, cookie | 200, liked=1, likes_count |
| 9 | Пользователи / laboratory_synthesis_users_logout | cookie | 204, удаление cookie |
